# 📘 java-calculator-precourse

<br>

## Description

- 문자열에서 숫자를 추출해 더하는 **문자열 계산기**입니다.  
- 기본 구분자(쉼표, 콜론)와 커스텀 구분자를 지원합니다.
- 잘못된 입력에는 `IllegalArgumentException`을 발생시킵니다.

---

<br>

## How to run

```bash
./gradlew run
```

<br>

## Function list

### 1️⃣ 구분자를 기준으로 분리한 각 숫자의 합 반환

- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우,
- 구분자를 기준으로 분리한 각 숫자의 합을 반환합니다.
- 빈 문자열("") 혹은 공백만 입력한 경우 0을 반환합니다.

|입력|	설명|	출력|
|---|---|---|
|`""`	|빈 문자열|	결과 : 0|
|`"1,2"`	|쉼표 구분자 사용	|결과 : 3|
|`"1,2:3"`	|쉼표 + 콜론 혼합	|결과 : 6|

<br>

### 2️⃣ 커스텀 구분자 사용 기능

- "`//{구분자}\n{숫자}`" 형식으로 입력받을 수 있습니다.

- {구분자}에 지정한 문자로 숫자를 분리하여 합을 계산합니다.

- 계산 결과는 "결과 : {값}" 형태로 출력됩니다.

|입력	|설명	|출력|
|---|---|---|
|`//;\n1;2;3`	|세미콜론(`;`) 구분자 사용|	결과 : 6|
|`//#\n4#5#6`	|해시(`#`) 구분자 사용	|결과 : 15|

💡 환경에 따라 실제 개행(`\n`) 대신 문자열 `\\n`으로 입력될 수 있으며, 두 경우 모두 허용됩니다.

<br>

### 3️⃣ 예외 처리 기능

- 입력값이 아래 어느 하나라도 해당되면 `IllegalArgumentException`을 발생시킵니다.
- 프로그램 종료는 `System.exit()`가 아닌 예외 전파 방식으로 처리합니다.

|구분	|조건|	예시(예외 발생)|
|---|---|---|
|음수 입력|	각 숫자는 0 이상이어야 함|	`-1,2,3`, `//;\n1;-2;3`|
|숫자 형식 오류|	문자, 기호, 소수점 포함 불가|	`1,a,3`, `1,2.5,3`, `1,+2,3`|
|빈 값|	연속된 구분자 또는 선두/후미 구분자 금지|`1,,2`, `,1,2`, `1,2,`, `//;\n1;;3`, `1::2`|
|커스텀 구분자 형식 오류|	입력 형식 위반 시 예외 발생	|`//;\n(내용 없음)`, `//**\n1**2(2글자 구분자)`, `//;1;2;3(개행 누락)`, `//\n1(구분자 없음)`|
