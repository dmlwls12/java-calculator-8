# java-calculator-precourse

## 문자열 계산기 구현 기능 목록

1. 구분자를 기준으로 분리한 각 숫자의 합 반환
- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환할 수 있다.

2. 커스텀 구분자 사용 기능
- "//{구분자}\n{숫자}" 형태로 입력받을 수 있다.
- 계산 결과는 "결과 : {값}" 형태로 출력한다.

3. 예외 처리 기능 
입력값이 아래 어느 하나라도 해당하면 IllegalArgumentException을 발생시킨다.
프로그램 종료는 System.exit() 가 아닌 예외로 처리한다.

- 분리된 각 숫자는 0 이상의 정수여야 한다.
- 각 숫자는 정수 형태여야 하며 문자, 소수점, 기호를 포함할 수 없다.
- 구분자 사이에 값이 비어 있거나 시작과 끝에 구분자가 있는 경우 허용하지 않는다.
- 입력 형식이 //{구분자}\n{숫자들} 혹은 //{구분자}\\n{숫자들} 을 따라야 한다.
